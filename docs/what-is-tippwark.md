# What does Tippwark mean?

The name **Tippwark** bridges digital software development and grounded, traditional craftsmanship:

* **Tipp** – Derived from typing on a keyboard (code / input).
* **Wark** – The Low German / Plattdeutsch word for *work* or *craft*.

Combined, **Tippwark** represents the craft of writing code — straightforward, grounded, and pragmatic.
